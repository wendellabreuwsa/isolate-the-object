# ClearCut BG

Projeto:

Programa que irá importar arquivos de imagens(Arquivos com backgroud em cores estáticas, todo branco, todo preto, etc.)

A interface deve ser limpa, simples e intuitiva, com as únicas funções sendo:

Importar arquivo de imagem: Abre o diretório, importa os arquivos (.png, .jpg, etc.); Mostra uma tela com as imagens contidas;

Função principal: Remover o fundo da imagem e tranformá-la em um PNG sem fundo, não apenas mudar o fundo da imagem, mas sim, removê-lo;

Uma opção de ajustar a tolerância para isolar o fundo da imagem corretamente;

Opção para salvar a imagem ajustada, com o fundo removido;

Estou anexando uma imagem como exemplo, do conteúdo esperado para ser editado, a imagem contém um foguete, e o fundo da imagem é todo branco, a função da aplicação será remover o fundo branco, mantendo somente o objeto foguete;

A interface da aplicação deve ser escura;
